The useful distinction

A timer remembers. This clock measures.

Generic counters increment their last answer. That makes them drift, start at zero, and lose their place when a tab sleeps. since-clock asks the platform for the current time and subtracts the fixed epoch. A day here is exactly 24 hours, not a calendar-day calculation.

Correct after absence

Hide the tab, return tomorrow, or cross a daylight-saving change. The next reading is calculated from the same instant.

02

Quiet by default

Tabular numerals prevent layout jitter. Reduced motion removes wheels and spatial transitions while keeping the reading live.

03

Readable in the source

Use semantic <time>, copy two files, and keep a truthful fallback in the markup for no-script and invalid-input cases.

Quick start

Useful in one copy-paste.

Keep the fallback phrase human. The script upgrades it only when the epoch is parseable and already in the past.

<time datetime="2026-05-27T18:40:53-07:00"
      data-since="2026-05-27T18:40:53-07:00">
  <span data-since-value>since 27 May 2026</span>
</time>

<link rel="stylesheet" href="since-clock.css">
<script src="since-clock.js" defer></script>
